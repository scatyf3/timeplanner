# Apple Watch：用快捷指令「记一段」

手表上不写原生 app：一个快捷指令往 Google 日历的「Actual」日历写一段事件，和 softbar / `timeplanner log`
写的是同一条 ②Actual 时间线。适合离开电脑的时段：健身、出门、吃饭。

## 前提

1. `.env` 里 `TIMEPLANNER_BACKEND=gcal`，`GCAL_ACTUAL_ID` 是你的「Actual」日历（见 README「配置 Google Calendar」）。
2. iPhone「设置 → 日历 → 账户」里添加这个 Google 账户，打开「日历」开关，确认系统「日历」App 里能看到「Actual」。
   快捷指令写进去的事件会同步回 Google 日历。

## 建快捷指令「记一段」（在 iPhone 的「快捷指令」App 里建，手表自动同步）

按顺序加这些操作（菜单名以你系统语言为准）：

1. **从菜单中选取**，提示「在干嘛」，5 个选项：`main`、`side`、`life`、`health`、`fun`。
   每个分支里放一个 **文本**，内容就是这个词，后面接 **设定变量** `bucket`。
2. **从列表中选取**，列表 `15 / 30 / 45 / 60 / 90 / 120`，提示「多久前开始的（分钟）」，结果存成变量 `分钟`。
3. **请求输入**（文本），提示「描述（可跳过）」，存成变量 `描述`。手表上可以用听写。
4. **当前日期** → **调整日期**：减去 `分钟` 分钟，存成变量 `开始`。
5. **添加新日程**：日历选「Actual」，标题 `[bucket] 描述`，开始 `开始`，结束 **当前日期**，关掉提醒。
6. **显示通知**：`已记 [bucket] 描述`。

最后在快捷指令的详情里打开「在 Apple Watch 上显示」，再把它加到表盘的快捷指令复杂功能上，一抬手就能点。
某一步如果手表上跑不了，系统会交给配对的 iPhone 执行。

## timeplanner 怎么认这些事件

- 快捷指令建的事件没有 timeplanner 标记，所以在 Actual 里显示成外部事件（🔒），planner 永远不会改写或删除它。
- 它的 bucket 从标题开头读：`[fun] 打塔`、`fun 打塔`、`health：健身` 都行（`core/classify.explicit_bucket`）。
  周报按这个算各 bucket 的小时数；标题开头没写 bucket、也没有日历颜色的，算「其他」。

## 想更快的话

为最常用的一两个场景各建一个「一键」快捷指令，跳过菜单和描述，比如「健身 60 分钟」：
固定 `bucket = health`、`分钟 = 60`、标题 `[health] 健身`。
